# 国际象棋联机（astrbot_plugin_gjxq_chess）

![version](https://img.shields.io/badge/version-v1.5.0-blue)
![python](https://img.shields.io/badge/python-3.10%2B-blue)
![license](https://img.shields.io/badge/license-MIT-green)

在 [HullQin 游戏大厅](https://game.hullqin.cn/gjxq/) 的 gjxq 国际象棋房间里，通过聊天完成：看棋盘、
走棋、认输、重开，并可选让机器人自动用 AI 和你对弈。

> **注意**：`gjxq` 是站点里的**国际象棋**（不是中国象棋；中国象棋在 `/xq/`，本插件不适用）。
>
> 本插件是非官方第三方工具，与 hullqin 及其游戏站点无隶属关系。
>
> 当前版本：v1.5.0（更新内容见 [CHANGELOG.md](CHANGELOG.md)）。
>
> 仓库：https://github.com/Karuha-4B6172/astrbot_plugin_gjxq_chess

## 功能

- **创建 / 加入房间**：房间链接形如 `https://game.hullqin.cn/gjxq/<房间号>`（房间号 3-8 位小写字母或数字）。
- **文本棋盘**：Unicode 棋子 + 文件/行号坐标，按玩家执棋方向翻转，并标注最后一步。
- **聊天走棋**：`e2e4`、`g1f3`、升变 `e7e8q`，非法走法会给出中文提示。
- **自动 AI + Elo 难度**：基于 python-chess 的 alpha-beta 搜索；可用近似 Elo 分（600-2400）设置难度，也可用 `/象棋 难度` 在聊天里随时调整；关闭 Elo 时按深度/思考时间自定义。
- **计时模式**：网站开启“操作计时”后，机器人走棋会按站点规则正确累计用时，不会让计时归零。
- **悔棋回应**：对手在网页请求悔棋时，机器人会自动同意（默认）或拒绝（可配置 `auto_accept_undo`）。
- **主动通知（默认关闭棋盘推送）**：对手/AI 走棋、轮到你走棋、胜负结果可主动推送；棋盘默认不推送，可用配置开启，并按 `board_batch_plies` 合并多步后一次发送，避免刷屏。
- **多开**：同一个群/私聊可同时开多个房间（`/象棋 列表` 查看、`/象棋 切换` 切换、`/象棋 离开 [房间号]` 单独离开），并发房间总数可配置（默认 5）。
- **自动入座 / 自动开局**：机器人自动占座，房主场景下双方入座后自动开始；
  `/象棋 离开` 会先主动离座（对局中且机器人为房主时会先结束对局），避免“假离开”。
- **离座 / 入座**：`/象棋 离开座位` 留在房间观战，`/象棋 入座 [座位号]` 重新入座。

## 安装

1. 将整个 `astrbot_plugin_gjxq_chess` 目录放入 AstrBot 的 `data/plugins/` 下。
2. 安装依赖（插件依赖管理会自动读取 `requirements.txt`，也可手动执行）：

   ```bash
   python -m pip install "python-chess>=1.11.0"
   ```

3. 在 AstrBot WebUI 的插件管理中重载/启用插件，按需修改插件配置。
4. 确保 AstrBot 所在机器能访问 `game.hullqin.cn`（HTTPS + WSS）。

`python-chess` 缺失时插件仍可加载，但自动 AI 不可用，只能手动走棋。

## 指令

所有指令均以 `/象棋` 开头（部分带别名）：

| 指令 | 别名 | 说明 | 示例 |
| --- | --- | --- | --- |
| `/象棋 帮助` | `/帮助象棋` | 查看全部指令 | `/象棋 帮助` |
| `/象棋 创建 [房间号]` | — | 创建房间；省略房间号时随机生成 5 位 | `/象棋 创建`、`/象棋 创建 abc12` |
| `/象棋 加入 <房间号>` | — | 加入已有房间（也可直接粘贴房间链接） | `/象棋 加入 abc12` |
| `/象棋 列表` | — | 查看本会话开着的所有房间（多开） | `/象棋 列表` |
| `/象棋 切换 <房间号>` | — | 切换当前操作的房间 | `/象棋 切换 abc12` |
| `/象棋 开始` | — | 房主在双方入座后开始对局 | `/象棋 开始` |
| `/象棋 棋盘` | — | 查看当前棋盘（等待/对局中/结束均可） | `/象棋 棋盘` |
| `/象棋 状态` | — | 房间、身份、座位、最近走棋与 FEN | `/象棋 状态` |
| `/象棋 走 <走法>` | — | 按 UCI 格式走棋 | `/象棋 走 e2e4`、`/象棋 走 e7e8q` |
| `/象棋 AI 开\|关` | — | 开关当前房间的自动 AI 走棋 | `/象棋 AI 关` |
| `/象棋 难度 [Elo\|关]` | — | 查看/设置 AI 近似 Elo 难度（600-2400），`关` 恢复按深度 | `/象棋 难度 1000` |
| `/象棋 认输` | — | 认输当前对局 | `/象棋 认输` |
| `/象棋 重开` | — | 对局结束后重开（机器人执白） | `/象棋 重开` |
| `/象棋 离开座位` | `/象棋 观战`、`/象棋 离座` | 离开座位但留在房间观战（对局中且为房主会先结束对局） | `/象棋 离开座位` |
| `/象棋 入座 [座位号]` | `/象棋 坐下` | 重新入座；不填座位号时坐第一个空位 | `/象棋 入座`、`/象棋 入座 2` |
| `/象棋 离开 [房间号]` | — | 离开指定房间（会先主动离座）；不填则离开当前房间 | `/象棋 离开`、`/象棋 离开 abc12` |
| `/象棋 房间` | — | 查看房间号、链接、座位与连接状态 | `/象棋 房间` |

只有以上指令消息会触发插件，普通聊天不会被插件处理。

## 典型玩法

### A. 机器人在聊天里建房，人类用浏览器加入（人机对战）

1. 群里发送 `/象棋 创建`，机器人返回房间链接并自动入座 1 号位（房主，执白）。
2. 人类打开链接，在网页点击“入座”占 2 号位（黑方）。
3. 双方入座后自动开局；机器人执白并由 AI 自动走棋，人类在网页走黑棋。
4. 默认不主动推送棋盘：随时发送 `/象棋 棋盘` 查看；如需自动推送，在配置中开启 `notify_opponent_move` / `board_push_enabled`（并按 `board_batch_plies` 合并，防止刷屏）。

### B. 人类在网站建房，机器人加入（人机对战）

1. 人类在 `https://game.hullqin.cn/gjxq/` 创建房间并留在网页。
2. 群内发送 `/象棋 加入 <房间号>`，机器人自动占用空余座位（通常是黑方）。
3. 人类在网页点击开始；机器人执黑，轮到黑方时 AI 自动走棋。
4. 想要更弱/更强的对手：发 `/象棋 难度 800` 或 `/象棋 难度 1800`。

### C. 关闭 AI，纯聊天走棋

1. 配置中关闭 `ai_enabled`，或发送 `/象棋 AI 关`。
2. 轮到机器人一方时，在聊天中发送 `/象棋 走 e2e4` 走棋；对手在网页走棋后，
   插件会推送对手走法与棋盘。
3. 适合“聊天里的真人一起指挥机器人下棋”的场景。

### D. 同一个群多开（同时进行多局）

1. 在同一个群连续发送 `/象棋 创建`、`/象棋 加入 <房间号>`，可同时开多个房间（受 `max_sessions` 限制）。
2. 发送 `/象棋 列表` 查看全部房间（▶ 标记当前房间），`/象棋 切换 <房间号>` 切换。
3. 之后的 `/象棋 棋盘`、`/象棋 走`、`/象棋 状态`、`/象棋 认输` 都作用于当前房间；
   多房间时主动推送会带【房间号】前缀。
4. `/象棋 离开 <房间号>` 只离开指定房间，`/象棋 离开` 离开当前房间。

## 配置

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ai_enabled` | bool | `true` | 是否自动 AI 走棋 |
| `auto_accept_undo` | bool | `true` | 对手请求悔棋时自动同意；`false` 时自动拒绝 |
| `ai_elo` | int | `0` | 近似 Elo 难度（600-2400）；0 = 关闭，改用 `ai_depth` / `ai_time_limit` |
| `ai_depth` | int | `3` | 自定义模式的搜索深度（1-6，越大越慢越强；仅 `ai_elo=0` 时生效） |
| `ai_time_limit` | float | `2.0` | 单步思考时间上限（秒）；Elo 模式下作为时间上界 |
| `auto_start` | bool | `true` | 机器人是房主且双方入座后自动开局 |
| `move_delay` | float | `0.8` | AI 走棋前等待秒数 |
| `emoji` | string | `😀` | 入座时展示的表情（匿名玩家建议保留非空） |
| `max_sessions` | int | `5` | 机器人同时保持的房间连接数上限（支持同群多开） |
| `notify_opponent_move` | bool | `false` | 是否主动推送对手/AI 走棋消息（关闭时用 /象棋 棋盘 查看） |
| `board_push_enabled` | bool | `false` | 主动推送时是否附带棋盘（默认关闭，避免刷屏） |
| `board_batch_plies` | int | `4` | 累计多少步后合并推送一次；1 = 每步都推 |

## AI 难度（近似 Elo）

- 配置 `ai_elo` 或聊天指令 `/象棋 难度 <600-2400>` 设置；`/象棋 难度` 查看当前难度，
  `/象棋 难度 关` 恢复按 `ai_depth` 的自定义搜索。
- 难度映射是**近似模型**（不是真实等级分）：越高 → 搜索越深、思考越久、容许的走法分差越小、
  随机失误越少；低段位会像新手一样偶尔走明显不好的棋，但不会错失一步杀。
- 参考档位：

  | Elo | 大致水平 | 搜索深度 | 思考上限 | 随机失误 |
  | --- | --- | --- | --- | --- |
  | 600 | 入门 | 1 | 0.4s | ~35% |
  | 800 | 简单 | 1 | 0.6s | ~28% |
  | 1000 | 普通 | 2 | 0.8s | ~20% |
  | 1200 | 进阶 | 3 | 0.9s | ~16% |
  | 1600 | 较难 | 4 | 1.3s | ~7% |
  | 2000 | 困难 | 5 | 1.6s | ~2% |
  | 2400 | 最强 | 5 | 2.0s | 0% |

- 同一局面 + 同一 Elo 的选择是确定性的（便于复盘）；Elo 模式从下一手棋开始生效。

## 开发与测试

仓库自带离线测试（不需要联网，不需要 AstrBot）：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

- `tests/test_codec.py`：与站点编码逐字节一致的棋局编解码（含王车易位、吃过路兵、升变、
  未动车被吃等黄金用例，`tests/fixtures/golden_sample.json`）。
- `tests/test_protocol.py`：房间 WebSocket protobuf 编解码。
- `tests/test_session.py`：房间会话状态机（离座/入座、结束游戏后重开、AI 调度回归）。
- `tests/test_render.py`：文本棋盘/走棋列表渲染。
- `tests/test_ai.py`：AI 走法合法性、一步杀、Elo 档位。

## 注意事项与限制

- **非官方插件**：站点协议由网页脚本逆向得到，hullqin 若改动字段或校验，插件可能暂时失效。
- **网络与 Cookie**：连接房间需要先访问站点获取匿名 `gid` Cookie，因此 AstrBot 必须能直连站点；
  代理/防火墙环境下可能连接失败，失败原因会在聊天中提示。
- **AI 强度有限**：默认深度 3 的启发式搜索，适合休闲对局，不是强引擎。
- **房间规则以网站为准**：王车易位、吃过路兵、升变、悔棋、认输等行为与网页一致；
  插件不处理网页端的悔棋请求。
- **多开上限**：同一会话可开多个房间，总数受 `max_sessions` 限制；插件卸载/停用时会自动断开所有房间。
- **离开房间会先离座**：网页端“直接断开连接”只会把玩家标记为离线、座位仍占用；插件现在会先发送离座操作并等待服务器确认，
  再断开连接。若对局进行中且机器人不是房主，服务器不允许离座，此时会提示并只能断开（等房主结束对局后网页会清理座位）。
- **文本棋盘**：棋子使用 Unicode 符号并以代码块包裹，个别手机客户端字体不等宽，排版可能有轻微错位。
- **推送策略**：默认不主动推送棋盘；开启后由 `board_batch_plies` 控制合并步数。合并期间最后几步也一定会发出（对局结束时立即补齐）。
- **升变默认**：不带升变字母时默认升变为后（`e7e8` 等同 `e7e8q`）。
